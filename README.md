# Kapda Godam — 11 CR Wholesale E-Commerce

A wholesale clothing e-commerce application for **Kapda Godam, Ulhasnagar 5**, focused on the **11 CR** clothing brand.

## Overview

The application provides a digital catalog and wholesale ordering workflow for men's jeans and shirts.

## Key Features

- Product catalog for jeans and shirts
- Product search and filtering
- Size and color selection
- Wholesale/MOQ-aware cart
- Wholesale order submission
- Customer enquiry capture
- Admin product management
- Order status management

## Tech Stack

- React
- TypeScript
- FastAPI
- MongoDB
- Tailwind CSS
- REST APIs

## API Areas

- Products and categories
- Orders
- Customer enquiries
- Admin authentication
- Product management
- Order status management
